BRAR SALAT TIME — MOBILE SOURCE PACKAGE

Is ZIP mein Android Studio source project (app.zip ke andar) aur build workflow files hain.

Mobile se upload karne ke liye:
1. ZIP ko phone mein download karein.
2. ZIP ko extract karein.
3. Extracted barar-salat-time-main folder ko GitHub par repository mein upload karein.
4. Repository ke Actions tab mein Android Build workflow run karein.
5. Build successful hone par workflow ke Artifacts section se APK download karein.

Zaroori:
- Yeh SOURCE ZIP hai, install karne wala APK nahi.
- Is package se naya APK yahan build ya device par test nahi kiya gaya.
- Home dashboard par current time har second update hota hai.
- Prayer Awwal/Aakhir waqt ke liye Settings mein GPS location allow karein ya Manual City set karein.
- Nearby screen ke mosque cards ab readable hain; built-in masjid names/timings demo data hain, verified live masjid records nahi.
